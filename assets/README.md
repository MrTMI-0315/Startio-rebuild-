# Assets

출처와 브랜드 역할을 기록한 모바일 자산과 배포 후보 자산을 둔다. 앱 번들·스토어·홍보물에는 권리와 노출 위치가 확인된 자산만 사용한다.

## 폴더

- `brand/corporate/`: 개발·운영 주체의 corporate identity. 제품 브랜드와 분리해서 사용한다.
- `brand/product/`: Startio 제품 브랜드 전용 자산. 승인된 제품 워드마크·앱 아이콘이 생길 때 사용한다.

## 사용 상태

- `approved`: 앱 번들·스토어·홍보 사용 가능
- `owner-provided-original`: 개발·운영 주체가 제공한 corporate 원본. 실제 노출 위치와 파생본은 별도 검증
- `pending-rights`: 원본은 보존하되 배포 권한 확인 전 제품에 포함하지 않음

각 외부 자산의 출처, 파일 정보, 해시, 사용 상태는 가까운 `README.md`와 루트 `ASSET_MANIFEST.md`에 기록한다.
