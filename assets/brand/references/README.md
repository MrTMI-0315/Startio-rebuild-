## Intake rules

1. Preserve source provenance and a byte-identical copy before design work.
2. Mark every reference as primary or secondary.
3. Separate facts to adopt from visual details to avoid.
4. Record licensing, ownership, redistribution, and trademark constraints.
5. Do not create SVG geometry, PNG derivatives, manifests, or contact sheets until the intake checklist is complete.
6. Once a design is explicitly approved, add an explicit `assets/brand/asset-plan.json` and run the existing SVG-to-PNG pipeline.
