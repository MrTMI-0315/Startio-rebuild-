# Startio CI placement study v0.1

## 결정 후보

- 기준 화면: iPhone 16e, 390×844pt
- 화면 안전 여백: 좌우 20pt
- CI 심벌 표시 크기: **72×72pt**
- @2x 래스터 대응: 144×144px
- @3x 래스터 대응: 216×216px
- 벡터·앱 아이콘 마스터: 1024×1024px
- 좌측 하단 배치: leading 20pt, bottom safe-area 위 20pt
- 워드마크 결합 시 간격: 16pt

## 72pt를 선택한 이유

1. 390pt 화면 폭의 약 18.5%로, 식별 가능한 브랜드 블록이면서 입력과 CTA보다 작다.
2. 8pt 그리드에 맞고 64pt보다 존재감이 크며 80~88pt보다 실행 UI와 경쟁이 적다.
3. 44pt iOS 최소 터치 영역보다 충분히 크므로 향후 설정 진입처럼 동작을 부여해도 별도 hit slop 없이 대응할 수 있다.
4. 360pt Android 화면에서는 64pt로 한 단계 축소할 수 있다.

## 비교 시안

- A — First Step: 작은 블록이 한 칸 앞으로 이동한다.
- B — Open Start: 닫힌 프레임이 열리며 시작점이 드러난다.
- C — Three Steps: Startio의 정확한 3단계 실행 계약을 직접 상징한다.
- D — Start Point: 중심점과 열린 코너로 막힘에서 방향을 만든다.
