# Startio MVP 핵심 정의

## 1. 제품 한 줄 설명

Startio는 사용자가 미루던 일을 즉시 실행할 수 있는 첫 행동으로 바꾸도록 돕는 AI 실행 코치다. 이를 위해 3단계 행동 분해, 타이머, 완료 인증 순환, 행동 이벤트 기록을 사용한다.

## 2. MVP 목표

MVP의 목표는 계획 앱을 만드는 것이 아니다.

MVP의 목표는 사용자가 "무엇을 해야 하는지는 알지만 시작할 수 없다"는 상태에서 "작은 첫 행동을 시작했다"는 상태로 이동하도록 돕는 것이다.

MVP는 다음 핵심 흐름이 작동함을 증명해야 한다.

```text
할 일 입력
→ 실행 장벽 분석
→ 3단계 행동 분해
→ 1단계 → 2단계 → 3단계 타이머
→ 최종 체크 인증 / 선택적 로컬 사진 / EXP(경험치)
→ 행동 이벤트 기록
→ 기본 KPI(핵심 성과 지표) 계산
```

## 3. 목표 사용자

### 핵심 사용자

- 20~30대 성인
- 만성적인 미루기나 ADHD와 유사한 실행 어려움을 겪는 사람
- 해야 할 일은 알지만 시작하기 어려운 사람
- 플래너, 할 일 앱, 캘린더, Notion 또는 집중 도구를 사용해 본 사람
- 주로 "해야 할 일을 인식하는 시점"과 "첫 행동을 하는 시점" 사이에서 실패하는 사람

### 대표 사용자 상황

```text
"논문을 써야 하는데 너무 벅차게 느껴져요."
"이력서를 시작해야 하는데 어디서부터 해야 할지 모르겠어요."
"방을 청소해야 하는데 계속 침대에 누워 있게 돼요."
```

## 4. 핵심 문제

사용자가 실패하는 주된 이유는 정보가 부족해서가 아니다.

시작 단계에 인지적·정서적 마찰이 있기 때문에 실패한다.

1. 할 일이 너무 크게 느껴진다.
2. 첫 행동이 명확하지 않다.
3. 시작하기 전에 실패할 것이라고 예상한다.
4. 더 쉬운 행동으로 도피한다.
5. 반복해서 미루면서 자기효능감을 잃는다.

Startio는 계획을 세운 뒤가 아니라 행동하기 직전의 순간에 개입한다.

## 5. 제품의 위치

Startio는 다음과 같은 제품이 아니다.

- 할 일 목록
- 범용 챗봇
- 심리 치료 서비스
- 의료 진단 도구
- 캘린더에만 초점을 둔 생산성 앱

Startio는 다음과 같은 제품이다.

- 행동 시작 개입 도구
- AI 실행 코치
- 행동 순환형 제품
- 비임상 웰니스·생산성 지원 도구

## 6. MVP 핵심 흐름

```text
1. 사용자가 할 일을 입력한다.
2. Startio가 할 일, 감정, 상황, 실행 장벽을 해석한다.
3. Startio가 3단계 행동 계획을 생성한다.
4. 1단계, 2단계, 3단계를 순차 타이머로 실행한다.
5. 사용자가 현재 타이머를 완료·일시정지·포기할 수 있으며, 앱을 다시 실행하면 현재 단계를 복구한다.
6. 3단계 뒤 사용자가 필수 체크 인증을 제출하고 선택적으로 로컬 전용 사진을 첨부할 수 있다.
7. Startio가 할 일·행동 계획마다 EXP(경험치) 30을 한 번 지급한다.
8. Startio가 실행 흔적 중심의 History(실행 기록)와 행동 이벤트를 저장한다.
9. Startio가 기본 KPI(핵심 성과 지표)를 계산한다.
10. Startio가 원문을 포함하지 않은 구조화 데이터로 이후 행동 크기 조정을 개선한다.
```

## 7. P0 범위

P0는 첫 번째 개발 목표다.

P0에는 다음 항목이 반드시 포함되어야 한다.

- Task(할 일) 입력
- 실행 장벽 분석
- 3단계 행동 계획
- 재진입 복구가 가능한 순차 단계 타이머·Focus Mode(집중 모드)
- 필수 완료 체크와 선택적 로컬 전용 최종 사진
- 할 일 단위 EXP(경험치) 1회 보상
- 실행 흔적 중심 History(실행 기록)
- 행동 이벤트 기록
- 기본 KPI(핵심 성과 지표) 계산

### P0 성공 기준

사용자가 다음 흐름을 처음부터 끝까지 완료할 수 있어야 한다.

```text
앱 열기
→ 할 일 입력
→ 3단계 행동 계획 받기
→ 1단계 → 2단계 → 3단계 타이머 완료
→ 체크 인증 제출(사진은 선택)
→ EXP(경험치) 받기
→ 완료 기록 확인
```

## 8. P1 범위

P1은 P0 핵심 흐름이 작동한 뒤 추가할 수 있다.

- 자유 입력 완료 인증
- 서버 사진 업로드·동기화
- 고급 실행 기록·보고서 차트
- 푸시 기반 재진입 미션
- 푸시 알림 기본 틀
- 최근 행동 기반의 행동 크기 조정
- 단순한 주간 목표 구조

## 9. P2 범위

P2는 명시적으로 요청받기 전까지 구현하지 않는다.

- 6주 프로그램 운영
- 기관 대시보드
- 관리자 보고서
- 고급 RAG(검색 증강 생성)
- sLLM(소형 언어 모델)·도메인 엔진
- B2B(기업 간 거래) 보안 배포
- 캘린더 양방향 동기화
- 전체 개인화 엔진

## 10. 비목표

다음 기능을 만들거나 다음과 같이 주장하지 않는다.

- ADHD 진단
- 의료 선별 검사
- 치료 효과
- 상담 대체
- 약물 조언
- 위기상담
- 전체 개인화 엔진
- 완성된 sLLM(소형 언어 모델)
- 기관 대시보드
- 완전한 B2B(기업 간 거래) 패키지

## 11. MVP 어조와 인상

제품은 다음과 같은 인상을 주어야 한다.

- 직접적임
- 부담을 줄일 만큼 따뜻함
- 행동 우선
- 낮은 마찰
- 모바일 우선
- 임상적이지 않음
- 공허한 동기 부여 문구가 아님

## 12. 핵심 제품 원칙

모든 주요 기능은 다음 질문에 답할 수 있어야 한다.

```text
이 기능이 사용자의 첫 행동 시작을 더 빠르게 돕는가?
```

그렇지 않다면 P0가 아니다.
